# Стань миллионером

Оригинальная браузерная игра-викторина на HTML, CSS и JavaScript без фреймворков.

## Что есть в игре

- 15 уровней и 15 вопросов за одну игру;
- 4 варианта ответа на каждом вопросе;
- случайный выбор вопроса для каждого уровня;
- случайное расположение вариантов ответа;
- экран победы после 15 правильных ответов;
- экран поражения при неверном ответе;
- возврат в главное меню после победы или поражения;
- три одноразовые подсказки: 50/50, мнение зала и совет эксперта;
- всплывающее окно прогресса между вопросами;
- сохранение лучшего уровня, побед и сыгранных игр через Yandex Player Data с fallback на `localStorage`;
- необязательные звуки и кнопка включения/выключения звука;
- безопасная интеграция SDK Яндекс Игр с fallback-режимом;
- адаптивная верстка для телефона, планшета и компьютера.

## Структура проекта

```text
index.html
style.css
game.js
questions.json
README.md
assets/sounds/
```

`index.html` должен лежать в корне проекта. При создании архива для Яндекс Игр важно, чтобы `index.html` оказался в корне архива, а не внутри дополнительной папки.

## Как запустить локально через Live Server

1. Откройте папку проекта в VS Code.
2. Установите расширение `Live Server`, если оно еще не установлено.
3. Откройте файл `index.html`.
4. Нажмите `Go Live` внизу окна VS Code.
5. Браузер откроет локальный адрес, обычно похожий на:

```text
http://127.0.0.1:5500/
```

## Как запустить локально через терминал

Откройте терминал в папке проекта и запустите:

```bash
python3 -m http.server 8000
```

Затем откройте:

```text
http://localhost:8000
```

Если порт `8000` занят, можно выбрать другой:

```bash
python3 -m http.server 8080
```

Тогда адрес будет:

```text
http://localhost:8080
```

## Как проверить игру без SDK

При локальном запуске файл `/sdk.js` обычно отсутствует. Это нормально.

Игра проверяет наличие `YaGames` безопасно. Если SDK недоступен, включается fallback-режим, и игра продолжает работать без ошибок.

Что проверить локально:

- стартовый экран открывается;
- кнопка `Играть` становится активной после загрузки вопросов;
- вопросы и ответы появляются;
- правильный ответ переводит к следующему вопросу;
- неверный ответ показывает экран поражения;
- кнопка звука работает;
- статистика сохраняется после завершения игры через `localStorage`.

## SDK Яндекс Игр

SDK подключен в `index.html` так:

```html
<script src="/sdk.js"></script>
```

Скрипт `/sdk.js` подключается в `<head>`, а `game.js` остается внизу `<body>`, чтобы элементы страницы уже были доступны для JavaScript. Такой путь нужен для публикации архива на Яндекс Играх. Не нужно скачивать `sdk.js` в проект и не нужно заменять путь на внешний URL.

В `game.js` используется безопасная инициализация через `YaGames.init()`. После готовности SDK или fallback-режима, а также после загрузки `questions.json`, игра один раз вызывает `ysdk.features.LoadingAPI.ready()`, если этот API доступен.

Язык определяется через `yandexSdk.environment.i18n.lang`. Сейчас игра поддерживает только русский язык `ru`; если SDK вернет другой язык или SDK недоступен локально, игра безопасно использует `ru`. В `game.js` есть `translations`, `getSupportedLanguage()`, `applyLanguage()` и `t()` — это основа для будущих переводов интерфейса без переписывания логики игры.

Fullscreen-реклама Яндекс Игр вызывается только в логических паузах и после действия игрока. В игре она запрашивается на переходах после 3-го, 6-го, 9-го и 12-го правильного ответа: сначала появляется окно прогресса с кнопкой `Далее`, а по нажатию сразу вызывается `ysdk.adv.showFullscreenAdv()`. Также реклама запрашивается при возврате в главное меню с экранов победы и поражения. Если SDK или реклама недоступны, игра просто продолжает работу без ошибки.

Rewarded-реклама используется как один `Второй шанс` за игру после поражения. Кнопка явно помечена второй строкой `(РЕКЛАМА)`. Поражение записывается в статистику сразу после неверного ответа, поэтому закрытие вкладки на экране поражения не теряет сыгранную игру. Если игрок нажимает кнопку и получает награду через `ysdk.adv.showRewardedVideo()`, игра переходит к следующему вопросу. Если после второго шанса игрок побеждает, победа и лучший уровень обновляют эту же игровую сессию без повторного увеличения `games`. Если ролик не досмотрен, игрок остается на экране поражения. На 15-м вопросе второй шанс не показывается, чтобы не выходить за пределы списка вопросов.

Статистика игрока сохраняется через Yandex Games Player Data: после `YaGames.init()` игра получает игрока через `ysdk.getPlayer({ scopes: false })`, загружает данные через `player.getData()` и сохраняет обновления через `player.setData(data, true)`. `localStorage` остается fallback-слоем: локальный прогресс объединяется с облачным, чтобы не потерять лучший уровень, победы и количество сыгранных игр.

Для ручной проверки Player Data в черновике Яндекс Игр: запустите игру из кабинета или debug-среды Яндекса, завершите партию, перезагрузите страницу и убедитесь, что лучший уровень, победы и сыгранные игры восстановились. Локально без `/sdk.js` проверяется fallback через `localStorage`.

## Где лежат вопросы

Все вопросы находятся в файле:

```text
questions.json
```

Сейчас в файле 120 вопросов: по 8 вопросов на каждый из 15 уровней.

## Как добавить новые вопросы

Добавляйте вопросы в `questions.json` в таком формате:

```json
{
  "level": 1,
  "question": "Сколько сторон у квадрата?",
  "answers": ["3", "4", "5", "6"],
  "correctIndex": 1,
  "explanation": "У квадрата четыре стороны."
}
```

Правила:

- `level` должен быть числом от `1` до `15`;
- `answers` должен содержать ровно 4 варианта;
- `correctIndex` должен быть числом `0`, `1`, `2` или `3`;
- правильный ответ должен находиться в массиве `answers` под номером `correctIndex`;
- `explanation` должен кратко объяснять правильный ответ;
- не добавляйте одинаковые вопросы;
- избегайте текущих событий, политики, религии, войн, цен, рейтингов и фактов, которые быстро устаревают.

Порядок вариантов в JSON может быть любым: во время игры варианты перемешиваются автоматически.

## Учтенные требования Яндекс Игр

- SDK подключается через `/sdk.js`;
- язык определяется через SDK, сейчас поддерживается только `ru`;
- локальный запуск без SDK не ломает игру;
- `YaGames.init()` вызывается безопасно;
- статистика сохраняется через Yandex Player Data, а при недоступности SDK использует `localStorage`;
- `LoadingAPI.ready()` вызывается один раз после загрузки вопросов и готовности SDK или fallback-режима;
- fullscreen-реклама вызывается через `ysdk.adv.showFullscreenAdv()` только после клика игрока в паузах игры;
- rewarded-реклама вызывается через `ysdk.adv.showRewardedVideo()` только по кнопке `Второй шанс` с пометкой `(РЕКЛАМА)`;
- игра обрабатывает `game_api_pause` и `game_api_resume`;
- при паузе текущие звуки останавливаются;
- после resume звук не включается насильно, если пользователь выключил его сам;
- добавлен fallback через `visibilitychange`, `blur` и `focus`;
- браузерное контекстное меню на игровом поле отключено;
- долгий тап не должен выделять элементы внутри игры;
- сохранен `focus-visible` для управления с клавиатуры;
- `html` и `body` не имеют системного скролла;
- постоянная шкала прогресса убрана из layout, вместо нее используется короткое всплывающее окно;
- проект не использует внешние библиотеки и картинки из интернета.

## Что проверить перед публикацией

- `index.html` находится в корне архива;
- в именах файлов и папок нет пробелов и русских символов;
- размер проекта меньше лимита Яндекс Игр;
- игра запускается локально без `/sdk.js`;
- в консоли нет явных ошибок при обычной игре;
- вопросы загружаются из `questions.json`;
- в `questions.json` минимум 100 вопросов, сейчас ожидается 120;
- нет одинаковых вопросов;
- на экранах 320, 375, 768 px и desktop нет системного скролла окна;
- кнопки ответов, подсказки и кнопка звука нажимаются;
- подсказки можно использовать только один раз за игру;
- статистика сохраняется через Yandex Player Data, а локально без SDK через `localStorage`;
- при победе и поражении игра возвращает игрока в главное меню;
- звуки не ломают игру, если файлов `mp3` нет;
- архив собран так, что `index.html` лежит в корне архива.
